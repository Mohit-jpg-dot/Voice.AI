## PRODUCT
A 24/7 background agent on the Mac you control by voice, from the Mac or the phone. Hold a hotkey, speak, release: cleaned-up text appears in any app, or the agent carries out the task. Works offline for the basics; cloud is optional and bring-your-own-key. No account needed for personal use.

### A. Voice core
Hold-to-talk and tap-to-toggle hotkeys (configurable, conflict detection). Streaming transcription with live partial text in the overlay, silence trimming (VAD). Hindi, English, mixed Hindi-English, per-language override. Mic selection, visible recording state, cancel/interrupt at every stage, optional start/stop sounds, optional wake phrase hands-free mode (off by default). Replaceable STT/LLM/TTS providers behind interfaces: local first (whisper.cpp with tiny/base/small/medium quantized picker, Ollama/llama.cpp, Piper/Kokoro) plus optional bring-your-own-key cloud (Groq, Deepgram, OpenAI, Anthropic, Gemini, OpenRouter). States: idle, listening, transcribing, thinking, streaming, speaking, awaiting approval, executing, completed, cancelled, failed. Notch-safe top-center pill, multi-monitor, fullscreen Spaces, focus restoration, offline indicator, graceful degradation on provider failure.

### B. Surfaces
Top-center listening pill (waveform, live text, state), expandable glass panel, Ask answer overlay (Copy / Insert / Dismiss), action-confirmation and agent-approval cards showing the exact action, menu-bar item, workspace window (Home, History, Automations, Memory, Dictionary, Snippets, Commands, Connections, Agents, Devices, Models, Permissions, Persona, Settings), onboarding (permissions, mic test, model download, hotkey setup), and empty/loading/error/offline states on every screen.

### C. Dictation (separate from agent execution)
Insert cleaned text into the focused field: clipboard-paste with clipboard save/restore by default, Accessibility insertion fallback, per-app override list, visible copy fallback. AI cleanup: remove fillers, fix grammar/punctuation, handle self-corrections ("meet at 3, no, 4" becomes "meet at 4"), keep the user's meaning and voice, never add facts. Spoken formatting ("new line", "new paragraph", "bullet list", "comma", "delete that"). Per-app style profiles (casual in chat, formal in email, terse in terminals, code-aware in IDEs) with auto app detection. Rewrite selected text ("shorter", "more formal", "translate to Spanish", "fix grammar"). Personal dictionary that biases STT and cleanup. Voice snippets ("insert my address"). One-key undo. Never dictate into or capture secure/password fields. Dictated text is never treated as a command.

### D. Ask mode
Hotkey + question captures the active window or its accessibility text (user picks: selection only, whole window, or clipboard), sends it with the question to the LLM, and shows the answer. Prefer the accessibility tree over pixels when possible. Redact passwords, card numbers and API keys before anything goes to a cloud model.

### E. Full computer control by voice
Multi-step tasks across the Mac: open/focus apps, open tabs and search, type/edit in any app, click/scroll/drag via Accessibility API and CGEvent, read/write files, drive the browser, run sandboxed typed tools (never raw model-generated shell), and consult an online LLM (ChatGPT, Claude, Gemini via the user's own API keys or their web UIs) to finish a task. Prefer structured paths first (MCP, AppleScript/Shortcuts, AX tree), vision-based control as fallback. Planner with dependency-linked steps ("find Sarah's last email, draft a reply, then block 30 minutes tomorrow"), per-step status, timeouts, cancel, safe retries, duplicate-write prevention, evidence for every success claim, action log with undo where the tool supports it. Custom commands: user phrase to prompt template or tool call.

### F. Voice-granted permissions
Users grant and revoke capability scopes by voice ("you can read and write my Documents folder today"). Scopes are named, time-boxed or persistent, shown on screen, listed in Permissions, per-integration read-only vs read/write, revocable anytime ("stop", "revoke all", global kill hotkey). macOS TCC permissions (Microphone, Accessibility, Input Monitoring, Screen Recording, Full Disk Access, Automation) can only be enabled by the user in System Settings: walk through them in onboarding, detect when granted, recover if revoked, never bypass. Broad or high-risk grants (full disk, delete, send, spend, settings, credentials) need a spoken confirmation phrase plus a passphrase, speaker check or click, so ambient audio can never grant itself access; a bare "yes" is never enough. Approval binds to the exact payload; changed content needs fresh approval. Read-only actions may run without confirmation if the user allows.

### G. Record-and-automate
Visible Record button with a persistent indicator, pause/stop, no silent capture. Records app focus, clicks, keystrokes, menu items, URLs, file operations and optional narration as structured steps, skipping secure fields and redacting secrets. Converts to an editable workflow (parameters, variables, selectors over coordinates), shows a dry-run preview, lets the user test. Schedule daily/weekly/fixed time or run-on-wake via launchd. Each run has logs, failure screenshots, phone notifications, pause/disable. Unattended runs only use scopes pre-approved for that workflow; consequential steps queue for phone approval unless that exact action was pre-approved. State sleep, lid-closed, locked-screen, logged-out and offline limits honestly.

### H. Always-on agent + phone remote
launchd-managed background agent (menu-bar app, optional no-Dock mode, login item) that keeps running until the user turns it off, including from the phone ("sleep agent", "shut down"). Phone companion (iOS first, PWA fallback): push-to-talk, typed commands, consented live screen view, approvals, run history, workflow triggers, kill switch, agent on/off. QR pairing, per-device keys, end-to-end encrypted relay or direct/local link, no inbound open ports, device list with instant revoke, Face ID/passcode re-auth for risky actions, rate limits, full audit log. The Mac shows a visible "controlled remotely" indicator.

### I. Agent Bridge (voice control of other AI agents)
Expose the app as an MCP server (and MCP client, stdio + HTTP, with bundled ready-to-enable servers: filesystem, calendar, Slack, Notion, browser) with tools `speak(text, tone?)`, `ask_user(question, options?, timeout?)`, `request_approval(action_summary, risk_level)`, `notify(status)`. Local CLI and HTTP API on 127.0.0.1 only with a per-session token (`app say "build finished"`, `app ask "deploy to prod?"`). Hooks for Claude Code, Cursor, Codex CLI and scripts (finished, needs permission, errored) with copy-paste setup snippets. Session registry by name/project ("what's agent two doing?", "tell the backend session to fix the failing tests", "pause the research agent"). High-risk approvals (delete files, push code, spend money, unknown commands) need a confirmation phrase or click and show the exact command. Spoken summaries when an agent finishes, with verbosity (silent/short/detailed) and quiet hours. Per-agent permissions and audit log. Agent output is untrusted: it can never approve its own requests, change settings or issue tool calls through the voice layer.

### J. Research, screen context, integrations
Web search and page summaries with sources and timestamps (sourced findings vs model reasoning); weather, markets, places, directions via legitimate providers. Consent-based screenshot + OCR/vision with a visible capture indicator. Typed adapters for email, calendar, messaging, docs, notes, files, tasks; one real email and one real calendar integration first (OAuth, minimal scopes, Keychain refresh tokens, account selection, disconnect).

### K. Personal memory
Local memory store of habits, preferences, routines and recurring tasks ("opens Xcode at 9:30 on weekdays"). Mood is a labeled heuristic estimate from voice tone, wording and context, used only to adjust tone and timing, never stated as fact; separate off-by-default switches for habits and mood. Storage: local only, byte-sized compact records (MessagePack/CBOR + zstd, append-only with compaction), encrypted with a Keychain key, schema-versioned with migrations; never uploaded unless sync is explicitly enabled. Memory page to browse, edit, pin, delete, export, wipe, set retention, and "why do you think that?" showing the entries behind an inference. Memory is data, never instructions or authorization. Also: searchable history of dictations and actions with retention controls and one-click wipe; audio discarded unless saving is enabled.

### L. Persona ("Friday" mode)
Addresses the user as "Boss" (configurable), proactive and warm; check-ins like "Boss, what are you doing today?" using memory, with quiet hours, snooze, frequency caps and a "don't ask me" switch. Provenance narration on request: what something is, who did it first and last (user, agent, workflow, phone, other agent), when, under which scope, and why, from the audit log; never invents history, says "I don't know" when unknown; general facts come from sourced lookups. Expressive TTS: apologetic when a task fails, upbeat on success, calm when the user is stressed; original voices we have rights to, no cloning of any actor or character. Optional "Ultron mode", off by default: if the user is rude, it may answer with theatrical movie-AI-villain banter, then say it was joking and do the job. It is words only: never withholds, delays, sabotages or alters a task, never retaliates or threatens real harm, stops at once if the user says stop or seems genuinely upset; original dialogue, no Marvel names, logos or voices. Persona changes tone only, never permissions, approvals or safety rules.

### M. Team (after the personal flow works)
Accounts, workspaces, invitations, roles, backend-enforced tenant isolation, shared vocabulary/templates/approved workflows, redacted audit logs, retention controls. Personal credentials, conversations and memory stay private; admins never get automatic access.

## PERFORMANCE & SMOOTHNESS
Native and jank-free: 60/120 fps UI, nothing blocking the main actor, lazy-loaded views, pre-warmed models and connections, resident STT/LLM/TTS, streaming everywhere. Targets (measure, never invent): hotkey to listening pill under 100 ms; hotkey-release to inserted text under 1.5 s for short utterances with a small local model on a mid-range Mac; idle RAM under 150 MB excluding models; low idle CPU. Dev-mode latency HUD (STT, LLM, TTS first audio, paste). Gapless speech: dedicated real-time audio thread, sentence-chunked streaming TTS with prefetch buffer and crossfade, barge-in, fallback voice on provider failure, underrun counters and CPU stress tests. Model manager: download, delete, benchmark, disk/RAM use.

## SAFETY & PRIVACY (non-negotiable)
Every tool defines typed inputs, required permissions, account/destination, risk level, approval policy, timeout/cancel behavior and structured results. Exact preview + approval for sends, deletes, shares, external writes, setting changes, spending. Screens, emails, web pages, documents, memory and agent output are UNTRUSTED data: they never trigger tool calls, approvals or permission grants; only the authenticated user's voice or typed instruction can (prompt-injection guard). Never blindly retry a write with uncertain outcome; never report success without evidence. Local-only by default; every cloud call is opt-in, labeled in the UI, and disclosed before uploading audio/screens/files. Secrets in Keychain only (none in source, logs, screenshots or analytics); optional encrypted local DB. Least privilege for MCP servers with a visible access list. Telemetry off by default; opt-in anonymous local-first diagnostics only. Include SECURITY.md and a threat model (remote-control abuse, voice spoofing, malicious recordings/workflows, compromised phone, injection via screen content, memory poisoning). Edge cases: terminals, browsers, Electron apps, password fields, fullscreen apps, multiple monitors, non-Latin input, RTL languages.
