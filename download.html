Installation & Setup Guide

1 Mount the Disk Image & Drag to Applications

Double-click the downloaded Voice.AI-1.0.0.dmg. In the Tahoe glass installer window, drag the Voice.AI icon into your Applications folder shortcut.

2 Opening an Unsigned Development Build (macOS Gatekeeper)

Because this build is created without a paid Apple Developer ID certificate, macOS Gatekeeper protects your Mac by requiring a one-time approval on first launch:

  • Recommended (1-Click): In your /Applications folder, Control-click (or right-click) Voice.AI.app and select Open. Click Open when the prompt appears.
  • Alternative: Go to System Settings → Privacy & Security, scroll down to the Security section, and click Open Anyway next to Voice.AI.
  • Developer Terminal: If preferred, remove quarantine metadata via terminal: xattr -dr com.apple.quarantine /Applications/Voice.AI.app

3 Required System Permissions

During first launch, Voice.AI will request the following standard macOS permissions to deliver low-latency voice execution:

🎙️ Microphone
Required for on-device Whisper transcription and streaming voice commands.
⌨️ Accessibility / Input
Listens for the fn key (tap for dictation, hold 250ms for agent).
🖥️ Screen Capture
Captures circled areas when visually querying on-screen content.
⚙️ Apple Events
Automates actions in Calendar, Mail, Notes, Chrome, and Finder.

4 Automatic Updates via Sparkle

Voice.AI checks for newer versions securely using Sparkle appcasts. You can check for updates anytime in the menu bar: Voice.AI → Check for Updates… or via the Appcast Feed.
