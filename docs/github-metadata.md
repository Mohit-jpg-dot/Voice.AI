## How to Set on GitHub (Right Side "About" Section)

1. Open your repository in your browser:
   👉 **[https://github.com/Mohit-jpg-dot/Voice.AI](https://github.com/Mohit-jpg-dot/Voice.AI)**
2. In the right sidebar at the top, find the **About** section.
3. Click the ⚙️ **gear icon** (Edit repository details) next to "About".
4. Configure the fields:
   - **Description**:
     `Voice-first AI computer agent for macOS & Windows. Speaks Hindi, English, and Hinglish. Offline local models, Cloud LLMs, and real computer control.`
   - **Website**:
     Check the box **"Use your GitHub Pages website"** or paste:
     `https://mohit-jpg-dot.github.io/Voice.AI/`
   - **Topics**: Add `voice-assistant`, `ai-agent`, `macos`, `windows`, `whisper`, `ollama`, `hindi`, `hinglish`.
5. Click **Save changes**.
